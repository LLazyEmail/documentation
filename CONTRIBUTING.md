# Contributing to LLazyEmail Documentation

Thanks for helping improve the docs. Prefer **small, focused pull requests** that a maintainer can review in a few minutes.

## Guidelines

1. **Keep existing content.** Restructure, fix, or annotate gently — do not delete docs wholesale. Prefer marking sections as legacy or moving material into an archive folder.
2. **One concern per PR.** Examples: fix frontmatter on one page, add a category label, tweak CSS tokens.
3. **Draft PRs are welcome** if you want early feedback.
4. **Match sibling sites.** This repo should stay aligned with [awesome-email-marketing](https://github.com/LLazyEmail/awesome-email-marketing) and [awesome-newsletters](https://github.com/LLazyEmail/awesome-newsletters) (Docusaurus 3.x, shared theme tokens, baseline files).
5. **No secrets in the tree.** Do not commit passwords, tokens, or private credentials.

## Suggesting a docs change

Open a PR that edits the relevant file under `docs/`, `blog/`, or site config. In the PR body, say why the change helps readers or maintainers.

## Reporting a broken link

Open an issue or PR. Prefer annotating a dead URL (⚠️ note) over silent deletion until a maintainer confirms.

## Code of conduct

Be respectful. See [`CODE_OF_CONDUCT.md`](./CODE_OF_CONDUCT.md) and [`SECURITY.md`](./SECURITY.md).
