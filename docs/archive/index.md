# Documentation archive hub

LLazyEmail documentation **does not delete** historical pages. Superseded material is either:

1. Annotated in place as legacy, or
2. Moved under the repository [`archive/`](https://github.com/LLazyEmail/documentation/tree/main/archive) folder with a stub left at the old docs route when URLs must stay stable.

See [`archive/README.md`](https://github.com/LLazyEmail/documentation/blob/main/archive/README.md) for the preserve-don't-delete policy.

This hub is part of reorganization tracking issue [#342](https://github.com/LLazyEmail/documentation/issues/342).
