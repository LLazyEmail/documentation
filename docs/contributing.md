# Contributing

Prefer **small, focused pull requests**. Keep existing content — annotate or archive instead of deleting.

Full guide: [CONTRIBUTING.md](https://github.com/LLazyEmail/documentation/blob/main/CONTRIBUTING.md).

## Quick rules

1. One concern per PR.
2. Draft PRs welcome.
3. Align with sibling Docusaurus repos when touching theme, config, or baseline files.
4. Do not re-add shared workflow copies owned by [documentation-actions](https://github.com/LLazyEmail/documentation-actions).
5. Never commit secrets.

See also the [Code of Conduct](https://github.com/LLazyEmail/documentation/blob/main/CODE_OF_CONDUCT.md) and [Security policy](https://github.com/LLazyEmail/documentation/blob/main/SECURITY.md).
